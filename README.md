#Automation Testing Cypress

Proyecto de automatizacion de pruebas desarrollado con Cypress para la automatizacion de pruebas.

El repositorio Contiene dos ejercicios principales:

1. Automatizacion E2E de un flujo de compra en SauceDemo.
2. Automatizacion de pruebas API sobre el recurso User de PetStore Swagger.

## Tecnologias Usadas

-Cypress
-JavaScript
-Node.js
-Git
